# AgriData Explorer: Understanding Indian Agriculture Through Data

## 📌 Project Summary
AgriData Explorer is a data analysis and visualization project focused on Indian district-level agricultural data (ICRISAT). It aims to uncover insights into crop production, yield trends, and area cultivated over time to support farmers, researchers, and policymakers.

## 📁 Project Structure

1. **AGRI.ipynb** - Data cleaning and preprocessing script
2. **cleaned_icrisat_agriculture_data.csv** - Cleaned dataset used for analysis
3. **Project analysisofEDA_ICRISAT_Agriculture_Final.ipynb** - Exploratory Data Analysis (EDA) notebook
4. **project_analysis_queries.sql** - SQL queries for analysis and insights
5. **AgriData_India_Dashboard.pbix** - Power BI dashboard for visual exploration
6. **Screenshots/** - Contains images of EDA plots and Power BI dashboard
7. **CropSelector** - Used for dynamic crop filtering in Power BI

## 💡 Key Features

- SQL Queries for:
  - Top Wheat Yield States
  - Oilseed Production Growth
  - State-wise Production Changes Over Years
- Power BI Dashboard with:
  - Dynamic slicers (e.g., crop selector)
  - State-wise comparisons
  - Historical crop trends
- EDA with Python:
  - Rice vs. Wheat production
  - Top crop-producing states
  - Yield comparisons across time and geography

## 📦 How to Use

1. Open `AGRI.ipynb` to see data preprocessing.
2. Use `project_analysis_queries.sql` inside MySQL to run project analysis queries.
3. Open `AgriData_India_Dashboard.pbix` with Power BI Desktop (June 2025 or later).
4. Use slicers and filters to explore state-wise insights interactively.

## 👨‍💻 Built With

- Python (Pandas, Matplotlib, Seaborn)
- MySQL
- Power BI Desktop
- Jupyter Notebook

## 🧠 Key Insights
- West Bengal and Uttar Pradesh consistently lead in rice and wheat production.
- Oilseed production shows high volatility and regional variation.
- Yield improvements are seen in maize, sunflower, and soybean in selected states.
